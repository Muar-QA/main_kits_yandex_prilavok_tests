# Автотесты для API Яндекс Прилавка.  
# Main.Kits - Создание набора.
## Описание проекта

Проект содержит автотесты для проверки API Яндекс Прилавка. Тесты проверяют поле `name` при создании набора (kit) для пользователя.

## Структура проекта

-  `configuration.py` -- URL стенда и пути для запросов к API

-  `data.py` -- тестовые данные (тело запроса для создания пользователя и набора)

-  `sender_stand_request.py` -- функции для отправки запросов на стенд

-  `create_kit_name_kit_test.py` -- тесты для проверки поля name при создании набора

-  `.gitignore` -- файл для исключения служебных файлов из репозитория

-  `README.md` -- описание проекта и инструкция по запуску

## Предварительные требования

-  Установленный Python версии 3.10 или выше

-  Установленный пакетный менеджер pip (обычно идёт вместе с Python)


-  Запущенный тестовый сервер Яндекс Прилавка

## Как запустить тесты

### Шаг 1. Распакуйте архив с проектом

Распакуйте скачанный архив в любую удобную папку на компьютере.

### Шаг 2. Запустите тестовый сервер

Запустите тестовый сервер, скопируйте URL сервера.  


### Шаг 3. Обновите URL в файле [configuration.py](http://configuration.py)

Откройте файл [`configuration.py`](http://configuration.py) в редакторе кода. Найдите переменную `URL_SERVICE` и замените её значение на актуальный URL вашего тестового сервера (из Шага 2).

### Шаг 4. Откройте терминал

Откройте терминал (командную строку) в папке с проектом. Это можно сделать несколькими способами:

-  В редакторе кода открыть терминал.

-  В **Windows**: откройте cmd или PowerShell и перейдите в папку проекта командой `cd путь/к/папке`

-  В **macOS/Linux**: откройте терминал и перейдите в папку проекта командой `cd путь/к/папке`

### Шаг 5. Создайте виртуальное окружение

В терминале выполните команду:

```bash
python -m venv .venv
```

### Шаг 6. Активируйте виртуальное окружение

-  **Windows**:

   ```bash
   venv\Scripts\activate
   ```

-  **macOS/Linux**:

   ```bash
   source venv/bin/activate
   ```

После активации в начале строки терминала появится `(venv)`.

### Шаг 7. Установите зависимости

В терминале (с активированным venv) выполните:

```bash
pip install requests pytest
```

### Шаг 8. Запустите тесты

В терминале (с активированным venv) выполните:

```bash
pytest create_kit_name_kit_test.py
```


Или запустите все тесты в проекте:

```bash
pytest . 
```

## Важные замечания

-  URL стенда в файле `configuration.py` должен быть актуальным. Стенды Яндекс Практикума временные и могут пересоздаваться.

-  Некоторые тесты вернутся с результатом FAILED. Это соответствует чек-листу проекта.
